# Study 1 results

One folder per run (`stage_id` = the config name in [`../configs/`](../configs/)), copied from the run outputs:
- `summary.json`: windows, mean/median primary-horizon DA, number of p < 0.05 cells, mean correlation and quantile
  coverage;
- `metrics.csv`: per (ticker, horizon) cell: n, DA, binomial p (raw and BH-adjusted), Wilson interval,
  Pearson/Spearman correlation, amplitude ratio, coverage, MAE;
- `metrics_aggregate.csv`: the same metrics averaged per horizon.

Predictions, plots and baseline tables stay local (they are regenerated by [`../run.ipynb`](../run.ipynb)). No prices
are included.
